# DS แลกเงินกีบ — โปรแกรมกรอกข้อมูล

โฟลเดอร์นี้มี **2 หน้า/โปรแกรมแยกจากกัน** เสิร์ฟจากตัวเสิร์ฟเว็บตัวเดียวกัน:

| หน้า | ใช้ทำอะไร |
|---|---|
| **`index.html`** — แลกเงินกีบ | กรอกรายการลงไฟล์ `DSแลกเงินกีบ....xlsx` โดย**เขียนกลับลงชีตเดิม** ไม่สร้างไฟล์ใหม่ ไม่แตะฟอร์แมตเดิม |
| **`slip-check.html`** — ตรวจสลิปซ้ำ | ลากรูปสลิปมาเช็คว่าเคยถูกบันทึกไปแล้วหรือยัง ไม่เกี่ยวกับไฟล์ Excel เลย |

ทั้งสองหน้ามีลิงก์สลับไปมาให้ในแถบด้านบน แต่**ทำงานแยกอิสระจากกันโดยสิ้นเชิง** — เปิดหน้าไหนก็ใช้ได้โดยไม่ต้องพึ่งอีกหน้า

ใช้ได้ทั้ง **บน PC** และ **บนแท็บเล็ต Android** — ดูหัวข้อ [ใช้บนแท็บเล็ต](#ใช้บนแท็บเล็ต) ด้านล่าง

## วิธีใช้ (บน PC)

ดับเบิลคลิก **`เปิดโปรแกรม.cmd`**

หน้าต่างดำจะเปิดค้างไว้ (คือตัวเสิร์ฟเว็บ) แล้วเบราว์เซอร์จะเปิดโปรแกรมขึ้นมาเอง
ใช้เสร็จแล้วปิดหน้าต่างดำได้เลย

> ต้องเปิดด้วย **Chrome หรือ Edge** — เบราว์เซอร์อื่นจะเขียนทับไฟล์เดิมไม่ได้
> (จะกลายเป็นดาวน์โหลดไฟล์ใหม่ชื่อเดิมมาให้แทน แล้วต้องเอาไปวางทับเอง)

ถ้าพอร์ต 8787 ชนกับโปรแกรมอื่น ให้เปิด PowerShell ในโฟลเดอร์นี้แล้วสั่ง

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8899
```

> **อยากให้ไฟล์อยู่บน OneDrive?** บน PC ไม่ต้องตั้งค่าอะไรเลย —
> แค่ย้ายไฟล์ `.xlsx` ไปไว้ในโฟลเดอร์ `OneDrive` ของเครื่อง แล้วกด **📂 เปิดไฟล์** เลือกจากตรงนั้น
> โปรแกรมเขียนทับไฟล์เดิมตามปกติ แล้ว OneDrive sync ขึ้นคลาวด์ให้เอง

### ขั้นตอนในโปรแกรม

1. กด **📂 เปิดไฟล์** แล้วเลือกไฟล์ `.xlsx` (หรือลากไฟล์มาวางก็ได้)
   — หรือกด **☁ เปิดจาก OneDrive** เพื่อเลือกไฟล์จาก OneDrive โดยตรง
2. เลือก**แท็บวันที่**ด้านบน — โปรแกรมเลือกแท็บที่ตรงกับวันนี้ให้อัตโนมัติ
3. กรอกฟอร์มทางซ้าย → กด **➕ เพิ่มลงคิว** (`Ctrl+Enter`)
   รายการจะขึ้นในตารางด้านขวาเป็น**แถบสีเหลือง** = ยังไม่ได้บันทึก
4. กรอกครบแล้วกด **💾 บันทึกลงไฟล์** (`Ctrl+S`) → เขียนลงไฟล์ Excel จริง

## ลากรูปสลิปเข้ามาได้เลย

เปิดไฟล์ `.xlsx` แล้ว **ลากรูปสลิปถอนมาวางที่ไหนก็ได้ในหน้าจอ** (หรือแคปหน้าจอแล้วกด `Ctrl+V`)
วางหลายรูปพร้อมกันได้ โปรแกรมจะอ่านให้แล้วสร้างแถวรอบันทึกให้ทีละรูป

| อ่านจากรูป | ลงช่อง |
|---|---|
| `USD 39.6` | **ยอด EPAY** |
| `Initiation time` และ `Arrival time` | **เวลาถอน** → `09.37-09.37` |
| วันที่ในสลิป | **วันที่** (คอลัมน์ A) |
| `Withdrawal successful` / `failed` | **✔️ / ❌** |
| — | **ยอดบาท** คิดกลับจาก USD ตามอัตราที่ตั้งไว้ (39.6 → 1,316) |

เหลือแค่เติม **ชื่อ** (และ ID ถ้ามี) — พิมพ์ลงในตารางได้เลย ช่องที่ยังขาดจะเป็นกรอบแดง
พิมพ์ ID ที่เคยมีแล้วชื่อจะเติมให้เอง กด `Enter` เพื่อกระโดดไปแถวถัดไป

> ใช้ **Tesseract.js** อ่านตัวอักษรทั้งหมด — ทำงาน**ในเบราว์เซอร์ล้วน ๆ ไม่ต่อเน็ต**
> ไฟล์ตัวอ่านและไฟล์ภาษา (ไทย + อังกฤษ) เก็บไว้ในเครื่องแล้วที่ `vendor/tesseract/`
> รองรับ**ทั้งไทยและอังกฤษพร้อมกันเสมอ** ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องมี Windows OCR
> ก่อนอ่าน โปรแกรมจะปรับภาพให้ก่อนอัตโนมัติ (ตัดขอบพื้นทึบ ปรับมุมเอียง เพิ่ม contrast
> และลับภาพเบลอเบา ๆ) ช่วยให้อ่านรูปถ่ายเอียง ๆ มัว ๆ ได้ดีขึ้น
> ป้ายมุมบนขวาบอกสถานะ (`⏳ กำลังโหลด` ตอนเริ่มเปิดหน้า → `🖼️ ลากรูปสลิปเข้ามาได้`)
> ตรวจยอดกับเวลาที่อ่านมาก่อนกดบันทึกทุกครั้ง — OCR อ่านผิดได้เสมอ โดยเฉพาะรูปเบลอมาก ๆ

### สลิปภาษาไทย

โปรแกรมแยกออกเองว่าเป็นสลิปไทย (ไม่มี Initiation / Arrival / USD) แล้วลงข้อมูลคนละแบบ

| อ่านจากสลิปไทย | ลงช่อง |
|---|---|
| เวลาที่ทำรายการ | **เวลายอดไทย** เช่น `9.37` |
| จำนวนเงิน | **ยอด True/Bank** (บาท) |
| — | **ไม่ใส่ EPAY** |

ยึดตามรูปแบบที่ไฟล์ใช้อยู่เดิม (แถวที่มีเวลายอดไทย จะมียอดบาทแต่ไม่มี EPAY)
ถ้าอยากให้เวลาลงช่อง **เวลาถอน** แทน เปลี่ยนได้ที่ **"การอ่านสลิปไทย"** ในฟอร์มซ้าย

> อ่านตัวหนังสือไทยได้เต็มที่แล้ว (ไม่ต้องติดตั้งอะไรเพิ่มเหมือนเดิม) แต่ OCR ยังพลาดได้
> โดยเฉพาะสลิปที่ถ่ายเอียง แสงสะท้อน หรือฟอนต์เล็กมาก — แถวที่อ่านค่าไม่ครบจะขึ้น
> กรอบแดงให้เติมเอง **ต้องตรวจทุกใบ** ก่อนกดบันทึก

## สิ่งที่โปรแกรมช่วย

| | |
|---|---|
| **จำ ID ↔ ชื่อ** | พิมพ์ ID ที่เคยมีแล้ว ชื่อจะเติมให้เอง — อ่านจาก **`customers.xlsx`** (ไฟล์รายชื่อกลาง) รวมกับทุกชีตในไฟล์ที่เปิดอยู่ |
| **คิด EPAY ให้** | ใส่ยอดบาท แล้วยอด USD คิดให้อัตโนมัติที่อัตรา **658 บาท = 19.8 USD** — แก้อัตราได้ในกล่อง "อัตราแลกเปลี่ยน" |
| **ปุ่มยอดที่ใช้บ่อย** | 658 / 1,316 / 3,290 / 6,580 / 13,160 |
| **ปุ่มเวลา "ตอนนี้"** | ใส่เวลาปัจจุบันรูปแบบ `HH.MM` และปุ่ม `=` ให้เวลาจบเท่าเวลาเริ่ม |
| **เตือนรายการซ้ำ** | ถ้า ID + เวลาถอน ตรงกับที่มีอยู่แล้ว จะถามก่อน |
| **ไฟล์สำรอง** | ติ๊ก "ดาวน์โหลดไฟล์สำรองก่อนบันทึก" ไว้ (เปิดไว้ให้แล้ว) จะได้สำเนาติดวันเวลาทุกครั้งที่บันทึก |
| **แก้ก่อนบันทึก** | รายการในคิวกดปุ่ม ✎ แก้ หรือ 🗑 ลบได้ ตราบใดที่ยังไม่กดบันทึก |
| **ลบของที่บันทึกแล้ว** | กด 🗑 แถวไหนก็ได้ แถวล่างเลื่อนขึ้นแทนที่ให้ |
| **กันเขียนทับกันเอง** | ตรวจว่าไฟล์ถูกแก้จากที่อื่นหรือยัง ก่อนบันทึกทุกครั้ง |

## ใช้บนแท็บเล็ต

มี 2 ทาง เลือกทางใดทางหนึ่ง

### 🅰 แอป Android (.apk) — ทางหลักที่ใช้อยู่

ติดตั้งเอง ไม่ผ่าน Play Store · ไม่ต้องใช้ Azure · ไม่ต้องใช้บัตรเครดิต
เปิดไฟล์ผ่านตัวเลือกไฟล์ของ Android ซึ่งเห็นทั้ง OneDrive, Google Drive และไฟล์ในเครื่อง
และแอป**ต่ออินเทอร์เน็ตไม่ได้เลยโดยตั้งใจ** (ไม่ได้ขอสิทธิ์ INTERNET)

👉 **[`APK.md`](APK.md)** — วิธี build วิธีติดตั้ง และข้อจำกัดที่ต้องรู้

### 🅱 เว็บ + OneDrive ผ่าน Microsoft Graph

เปิดจากเบราว์เซอร์ ใช้ได้ทุกที่ไม่ต้องลงแอป แต่ต้องต่อเน็ตตอนเปิด/บันทึกไฟล์
และต้องจดทะเบียนแอปที่ Azure ก่อน — **ถ้าบัญชี Microsoft เป็นบัญชีส่วนตัวที่ยังไม่เคยมี directory
จะต้องสมัคร Azure ซึ่งบังคับใช้บัตรเครดิต/เดบิตยืนยันตัวตน**

**ตั้งค่าครั้งเดียว** — ทำตาม **[`SETUP-ONEDRIVE.md`](SETUP-ONEDRIVE.md)**
สรุปคือ: เอาไฟล์โปรแกรมขึ้น GitHub Pages → จดทะเบียนแอปที่ Azure → เอา Client ID มาใส่ใน `config.js`

เสร็จแล้วบนแท็บเล็ตจะได้

- ไอคอนบนหน้าจอ เปิดเต็มจอเหมือนแอปจริง (กด **⬇ ติดตั้งแอป**)
- ปุ่ม **☁ เปิดจาก OneDrive** เลือกไฟล์ `.xlsx` ได้ทั้งจากไฟล์ล่าสุดและเรียกดูตามโฟลเดอร์
- กด **💾 บันทึกลงไฟล์** แล้วเขียนกลับลงไฟล์เดิมบน OneDrive ฟอร์แมต/สูตร/ดรอปดาวน์อยู่ครบเหมือนเดิมทุกอย่าง
- ปุ่ม / ช่องกรอก / ปุ่มในตาราง ขยายให้กดด้วยนิ้วได้ ตารางเลื่อนแนวนอนในกล่องของมันเอง

**ต้องต่อเน็ตแค่ตอนเปิดไฟล์กับตอนบันทึกเท่านั้น** — ตัวโปรแกรม การกรอกฟอร์ม และการอ่านสลิปด้วย OCR
ยังทำงานในเครื่องล้วนแบบออฟไลน์ (กด **📥 เตรียมใช้ออฟไลน์** หนึ่งครั้งตอนต่อ Wi-Fi
เพื่อเก็บตัวอ่านสลิป ~17 MB ไว้ในเครื่อง)

ข้อจำกัดเรื่องเน็ตมาจากตัว Android + OneDrive เอง — แอป OneDrive บน Android ไม่เปิดโฟลเดอร์
ให้เบราว์เซอร์เขียนไฟล์ได้เหมือนบน PC จึงต้องคุยผ่าน Microsoft Graph ซึ่งต้องออนไลน์

> ต้องล็อกอิน OneDrive ใหม่ประมาณ**วันละครั้ง** — เป็นกฎของ Microsoft เอง
> (refresh token ของเว็บแอปมีอายุ 24 ชั่วโมง) กดล็อกอินแล้วทำงานต่อได้เลย รายการที่ค้างอยู่ไม่หาย

### สองเครื่องแก้ไฟล์เดียวกัน

ตอนบันทึกลง OneDrive โปรแกรมส่ง **eTag** ของไฟล์ไปด้วย ถ้ามีใครแก้ไฟล์นั้นไปก่อน
OneDrive จะปฏิเสธการเขียน แล้วโปรแกรมจะถามว่าจะโหลดไฟล์ล่าสุดมาแล้วเพิ่มรายการต่อท้ายให้ไหม
— **ของเดิมไม่หาย** (โหมดไฟล์ในเครื่องยังใช้การเทียบลายเซ็นไฟล์เหมือนเดิม)

## รายชื่อ ID ↔ ชื่อ (`customers.xlsx`)

รายชื่อลูกค้าเก็บแยกไว้ในไฟล์ **`customers.xlsx`** (ไม่ได้อยู่ในไฟล์ธุรกรรมรายสัปดาห์)
เป็นตาราง 2 คอลัมน์ธรรมดา — คอลัมน์ A = ID, คอลัมน์ B = ชื่อ แถวแรกเป็นหัวตาราง

ทำแบบนี้เพื่อให้ **ใช้ชื่อร่วมกันได้ข้ามไฟล์ธุรกรรมทุกสัปดาห์** — เปิดไฟล์ `.xlsx` สัปดาห์ใหม่ ชื่อลูกค้าเก่าก็ยังเติมให้เหมือนเดิม
ไม่ต้องรอให้ ID นั้นโผล่ในไฟล์ปัจจุบันก่อนถึงจะจำได้แบบเมื่อก่อน

**ไฟล์นี้เก็บไว้ที่ไหน** ขึ้นกับว่าใช้โหมดไหนอยู่ — ป้าย **รายชื่อที่จำได้** บนแถบด้านบนบอกอยู่ (เอาเมาส์ชี้/แตะค้าง)

| สถานการณ์ | `customers.xlsx` อยู่ที่ |
|---|---|
| ล็อกอิน OneDrive อยู่ | โฟลเดอร์ **`DS-Entry`** บน OneDrive — **ใช้ร่วมกันทุกเครื่อง** |
| เปิดผ่าน `เปิดโปรแกรม.cmd` และไม่ได้ล็อกอิน | ข้าง ๆ `index.html` ในโฟลเดอร์นี้ (แบบเดิม) |
| นอกเหนือจากนั้น | ในเบราว์เซอร์เครื่องนั้น (IndexedDB) |

- **อ่านอัตโนมัติ** ทุกครั้งที่เปิดโปรแกรม
- **เขียนกลับอัตโนมัติ** ทุกครั้งที่กด **บันทึก** — ถ้าเจอ ID ใหม่ หรือชื่อที่พิมพ์ไม่ตรงกับที่มีอยู่ จะอัปเดตลง `customers.xlsx` ให้เอง (ไม่ต้องทำอะไรเพิ่ม)
- **แก้เองได้ตรง ๆ** เปิดไฟล์นี้ด้วย Excel แล้วแก้/เพิ่ม/ลบชื่อได้เลยเมื่อไหร่ก็ได้ (ปิดไฟล์ก่อนโปรแกรมจะเขียนทับรอบถัดไป)
- ถ้าไฟล์ปัจจุบันกับ `customers.xlsx` มีชื่อของ ID เดียวกันไม่ตรงกัน **ยึดตาม `customers.xlsx`** เป็นหลักเสมอ

## ตรวจสลิปซ้ำ (`slip-check.html`)

หน้านี้**แยกออกจากโปรแกรมแลกเงินกีบโดยสิ้นเชิง** — ไม่เกี่ยวกับไฟล์ Excel เลย ไม่มีฟอร์ม ไม่มีชีต
มีหน้าที่เดียว: ลากรูปสลิปมาวาง แล้วบอกว่าสลิปนั้นเคยถูกตรวจ/บันทึกไปแล้วหรือยัง

เปิดได้จากลิงก์ **🔎 ตรวจสลิปซ้ำ** ที่แถบด้านบนของหน้าแลกเงินกีบ หรือเปิดไฟล์ `slip-check.html` ตรง ๆ ก็ได้
(ต้องเปิดผ่าน `เปิดโปรแกรม.cmd` เหมือนกัน เพราะต้องใช้ตัวเสิร์ฟไฟล์ตัวเดียวกันในการบันทึกประวัติ)

ทุกครั้งที่ลากรูปสลิปเข้ามาแล้วอ่านสำเร็จ หน้านี้จะจำสลิปนั้นไว้ในไฟล์ **`slip_log.json`**
แล้วเทียบกับสลิปที่เคยตรวจมาก่อนหน้านี้ทุกครั้ง —
ไฟล์นี้ใช้ร่วมกันได้ตลอดไป ไม่ผูกกับไฟล์ธุรกรรมสัปดาห์ไหนทั้งสิ้น

ที่เก็บไฟล์เป็นกฎเดียวกับ `customers.xlsx` (OneDrive → โฟลเดอร์โปรแกรม → เบราว์เซอร์)
ป้าย **💾 ประวัติเก็บที่ …** บนแถบด้านบนของหน้านี้บอกอยู่ว่าตอนนี้ใช้ชุดไหน
ถ้าขึ้นเป็นสีเหลืองแปลว่าเก็บอยู่ในเบราว์เซอร์เครื่องเดียว — กด **☁ เชื่อม OneDrive** เพื่อใช้ร่วมกับเครื่องอื่น

**เกณฑ์เช็คว่าเป็นสลิปเดียวกัน** — ใช้ทั้ง 4 อย่างนี้ร่วมกัน:
- วันที่ + เวลา บนตราประทับของสลิป (เช่น `26/07/26 17:44:43`)
- **เลขอ้างอิง 1** — รหัสตัวอักษร+ตัวเลขปนกัน ขึ้นต้นด้วย `BONE` (เช่น `BONESIXRETG7OJXZ`) ไม่ซ้ำกันในแต่ละรายการ
- **เลขอ้างอิง 2** — กลุ่มตัวเลขที่อยู่ถัดจากเลขอ้างอิง 1 (เช่น `202 6072 6372 4718`)

เลือกใช้ 2 ค่านี้เป็นหลักเพราะเป็นตัวอักษร/ตัวเลขล้วน (ไม่ใช่ภาษาลาว) OCR จึงอ่านได้แม่นยำกว่าข้อความรอบ ๆ
และเป็นค่าที่ธนาคารออกให้ไม่ซ้ำกันในแต่ละธุรกรรมจริง ๆ

**ผลที่ขึ้นในตาราง**
- **✔ ใหม่ — บันทึกแล้ว** (สีน้ำเงิน) — ไม่เคยเจอมาก่อน บันทึกลง `slip_log.json` ให้อัตโนมัติทันที
- **⚠ สลิปซ้ำ** (สีแดง) — เคยตรวจมาก่อนแล้ว บอกวันเวลาที่เคยบันทึกไว้ด้วย — มีปุ่ม **ยืนยันบันทึกซ้ำ**
  ให้กดถ้ายังต้องการบันทึกซ้ำจริง ๆ (ไม่กดก็ได้ ถ้ากดแล้วแถวจะยังเทสีแดงเตือนไว้เหมือนเดิม ไม่หายไปไหน)
- **อ่านข้อมูลไม่พอจะเช็ค** — สลิปที่ OCR อ่านไม่เจอทั้งวันเวลาและเลขอ้างอิงเลย จะไม่ถูกบันทึก/เช็คซ้ำ (กันฟ้องเตือนผิด)

## เขียนลงไฟล์อย่างไร

โปรแกรม**ไม่ได้สร้างไฟล์ใหม่** แต่แก้เฉพาะจุดในไฟล์เดิม ส่วนที่ไม่เกี่ยวถูกคัดลอกไบต์ต่อไบต์
ทำให้สิ่งเหล่านี้อยู่ครบเหมือนเดิม

- ฟอนต์ **Mali ตัวหนา** จัดกึ่งกลาง ทุกเซลล์
- สีพื้นประจำคอลัมน์ — ID `#A2C4C9` · ชื่อ `#FFE699` · เวลาถอน `#00B0F0` · ยอดบาท `#92D050` · EPAY `#00FFFF`
- เส้นขอบ และรูปแบบตัวเลข (`d/m/yyyy`, `#,##0`, `#,##0.0`)
- **ดรอปดาวน์**คอลัมน์ แอป (`W/L/F/OA`) และ ✔️/❌
- **สูตร** `=SUM(...)`, ยอดบาท, ยอด US — สูตรไม่ถูกแตะต้อง และค่าที่แสดงถูกอัปเดตให้ตรงทันที

**เรื่องจำนวนแถว** — แต่ละชีตมีตาราง 6 บล็อกวางเรียงกัน (A–J, L–T, V–AD, AF–AN, AP–AX, AZ–BH)
โปรแกรมเติมบล็อกซ้ายสุดก่อน เต็มแล้วค่อยข้ามไปบล็อกถัดไปเอง
ตัวเลข `xx / yyy แถว` บนแถบด้านบนคือจำนวนที่ใช้ไปเทียบกับความจุทั้งชีต

## ลบรายการ

- **แถวสีเหลือง (ยังไม่บันทึก)** — กด 🗑 ตรงท้ายแถว หายทันที
- **แถวที่บันทึกลงไฟล์แล้ว** — กด 🗑 แถวจะขึ้นเป็น**ขีดฆ่าสีแดง** = รอลบ
  (กด ↺ เพื่อยกเลิก) แล้วกด **บันทึก** จึงจะลบออกจากไฟล์จริง

ลบแล้วแถวที่อยู่ล่างจะ**เลื่อนขึ้นมาแทนที่เอง** ไม่เหลือช่องว่างคาไว้กลางตาราง
ทำหลายแถวพร้อมกันได้ และจะยังไม่แตะไฟล์จนกว่าจะกดบันทึก

## แถวใหม่ไปอยู่ตรงไหน — เรื่องสำคัญ

ในหนึ่งชีตมีตารางหน้าตาเหมือนกัน **6 ชุด วางเรียงกันไปทางขวา**

| ชุด | คอลัมน์ | จำนวนแถว |
|---|---|---|
| 1 | **A–J** | 120 แถว (ชีต 27/7) หรือ 100 แถว (ชีตอื่น) |
| 2 | **L–T** | 100 แถว |
| 3–6 | V–AD, AF–AN, AP–AX, AZ–BH | ชุดละ 100 แถว |

พอ **ชุดแรก (A–J) เต็ม** แถวใหม่จะไปต่อที่ **ชุดที่ 2 (L–T)** ซึ่งอยู่ไกลไปทางขวา
ถ้าเปิด Excel แล้วดูแค่คอลัมน์ A–J จะ**ไม่เห็นแถวใหม่** ทั้งที่บันทึกสำเร็จแล้ว

โปรแกรมจึงบอกตำแหน่งให้ 3 จุด

- ป้ายบนหัวจอ: `⚠ A–J เต็ม (120 แถว) แถวใหม่ไปคอลัมน์ L–T`
- ในตาราง คอลัมน์แรกบอกตำแหน่งจริง เช่น `121 · L3 ⟶` (⟶ = อยู่นอกคอลัมน์ A–J)
- แถบหลังบันทึก: `แถวใหม่อยู่ที่ คอลัมน์ L–T (ตารางชุดที่ 2) แถว 5–6`

> ชีต **27072026** ตอนนี้ชุด A–J เต็มแล้ว แถวใหม่จะไปลง L–T เสมอ
> ถ้าอยากให้ลง A–J ต่อ ต้องไปเพิ่มแถวในไฟล์ Excel เอง (ขยายช่วงเหนือแถวผลรวม)

## ถ้าบันทึกแล้วข้อมูลไม่ขึ้นในไฟล์

หลังกดบันทึก โปรแกรมจะ**อ่านไฟล์กลับจากดิสก์มานับให้ดู**แล้วขึ้นแถบสรุปบนหัวจอ อ่านแถบนั้นก่อนเสมอ

| แถบที่ขึ้น | แปลว่า |
|---|---|
| 🟢 `บันทึกลงไฟล์แล้ว … ตรวจสอบจากไฟล์บนดิสก์: มี N รายการ` | เขียนลงไฟล์จริงเรียบร้อย |
| 🟡 `ดาวน์โหลดไฟล์ใหม่แล้ว …` | **ไฟล์ต้นฉบับยังไม่ถูกแก้** ไฟล์ใหม่ไปอยู่ในโฟลเดอร์ Downloads ต้องเอาไปวางทับเอง |
| 🔴 `บันทึกไม่สำเร็จ` | มีข้อผิดพลาด อ่านข้อความที่แสดง |

**สาเหตุที่พบบ่อยที่สุดคือแถวไปอยู่คอลัมน์ L–T** ไม่ใช่ไม่ได้บันทึก — ดูหัวข้อด้านบน

### ถ้าเปิดไฟล์ค้างไว้ใน Excel ด้วย

โปรแกรมจะตรวจก่อนบันทึกทุกครั้งว่า**มีใครแก้ไฟล์นี้หลังจากโปรแกรมเปิดมันไปหรือเปล่า**
(เช่น เปิดค้างใน Excel แล้วกดเซฟ หรือเปิดโปรแกรมนี้ไว้สองหน้าต่าง)

ถ้าเจอ จะถามก่อน — กด **OK** เพื่อโหลดไฟล์ล่าสุดแล้วเพิ่มรายการต่อท้าย (ของเดิมอยู่ครบ)
หรือ **Cancel** เพื่อยกเลิก ไม่เขียนอะไรเลย

ก่อนหน้านี้กรณีนี้จะเขียนทับของเดิมหายไปเงียบ ๆ — ตอนนี้แก้แล้ว
แต่ยังแนะนำให้ **ปิดไฟล์ใน Excel ก่อนกดบันทึก** อยู่ดี

เจอแถบ **สีเหลือง** แปลว่าเปิดโปรแกรมผิดทาง ให้ปิดหน้าเว็บแล้วเปิดใหม่ด้วย
**`เปิดโปรแกรม.cmd`** (ไม่ใช่ดับเบิลคลิก `index.html`) และใช้ **Chrome หรือ Edge**
สังเกตป้ายมุมบนขวาให้ขึ้นว่า **`✔ เขียนทับไฟล์เดิมได้`** ก่อนเริ่มกรอก

ครั้งแรกที่กดบันทึก Chrome จะถามว่าอนุญาตให้แก้ไฟล์นี้ไหม — ต้องกด **"บันทึกการเปลี่ยนแปลง"**
ถ้าเผลอกดปฏิเสธ โปรแกรมจะเปลี่ยนไปโหมดดาวน์โหลดแทนและบอกให้ทราบ

## ข้อควรระวัง

- ปิดไฟล์ `.xlsx` ใน Excel ก่อนกดบันทึก ไม่งั้นอาจเขียนทับไม่ได้
- ถ้าหน้าเว็บถูกปิดขณะยังมีรายการค้างในคิว รายการนั้นจะหาย (โปรแกรมจะเตือนก่อน)
- คอลัมน์ "แอป" จะค้างค่าเดิมไว้ให้กรอกเร็ว แต่ **✔️/❌ จะรีเซ็ตเป็น ✔️ ทุกครั้ง** กัน ❌ ติดค้างไปทั้งวันโดยไม่รู้ตัว
